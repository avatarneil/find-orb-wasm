Measured performance

Copy-on-write reference mounting avoids copying the full 110 MB pack for every fresh command. The session also retains immutable compiled code, avoiding repeated compilation work after garbage collection. Each job receives independent C globals, heap, filesystem, and random state. Both changes preserve orbital arithmetic.

Propagation improved by 1.15–1.43× in this run; fitting was essentially unchanged. The shipped optimizations reduce command setup and retain compiled code. They do not change the orbital integrator.

Native ARM long double has 53 significand bits; WASM has 113. Software binary128 arithmetic dominates the fitting workload. The port retains that precision, so native and WASM timing includes different extended-precision costs.

Link-time optimization Rejected

Accuracy checks passed, but exploratory fitting runs were slower and the binary was larger. The default build does not enable LTO. Measurements.

Exact integer multiplication Experimental

An exact limb-based replacement for compiler-rt multiplication has 31 proof obligations and independent integer/IEEE tests, including one million random binary128 products. It did not yield a reliable end-to-end fitting gain, so the shipped solver keeps the original runtime implementation. Differential evidence and solver measurements.

What correctness evidence establishes

Mathematical and compiler checks

Source-anchored SMT obligations cover search bounds, termination and insertion semantics; exact-real vector identities; floating-point reassociation/contraction counterexamples; and DE440 record-selection equivalence. The experimental helper has a separate source contract and exact-product proof.

Actual extracted routines pass 21,229 search and 50,121 vector cases across native O0/O3/sanitized and WASM O0/O3 builds. The compiler audit checks relaxed floating-point flags and ABI differences.

Astronomical and port checks

The seven workloads cover a short-arc fit with wide uncertainty, Ceres propagation/topocentric predictions and held-out recovery, plus high-eccentricity, near-parabolic, and hyperbolic retrograde trajectories. Ceres's maximum 30-day position error against the stored independent Horizons reference was 7.06 metres.

Native propagation must agree within 1 metre and 10 μm/s; independent sky predictions and held-out recovery must meet 0.1 arcsecond tolerances. Short-arc fitting retains observations and broad uncertainty.

These are targeted guarantees and empirical checks. They do not prove the full integrator, nonlinear fit, covariance calibration, compiler pipeline, or browser engine correct. Mathematical models still require reviewed correspondence to source; SMT results have not been independently proof-kernel checked.

6.33 MB download, with original coefficients

The default pack retains every auxiliary file and selects complete DE440 records for 2000–2040 plus boundary margins. No coefficients, physical constants, bodies, or sky-brightness data are approximated or discarded.

5,866,668 native components matched bit-for-bit at 2,859 epochs, covering record boundaries and adjacent floating-point values, all reader target codes, centres, and position/velocity modes. All seven complete WASM workloads also match scientific output exactly after excluding wall-clock metadata.

The actual ephemeris interval is (1999-11-22, 2040-02-08] in the ephemeris time scale. All intermediate integration and light-time queries must remain inside it. Missing data, read failures, and out-of-range queries reject the job; rough analytic fallback is disabled. Historical workloads can use a wider or full pack.

createSessionFromUrls() verifies the worker and bounded decompressed data, then initializes the session without a file chooser. Real Chromium tests cover repeated accurate computation, cancellation, and a cross-origin CDN that hides its gzip header. First-use offline operation still needs application packaging or caching.

Provenance and redistribution

Extracted from webastrometrica c86e53c, its latest origin/main when extraction began. Initial standalone commit: fe8a88d. Original file hashes are retained.

Builds use pinned sources and Emscripten, fresh checked source and library trees, and an explicit floating-point policy that ambient compiler flags cannot override. The corresponding-source archive includes upstream code and build recipes; its offline-source rebuild reproduced the same WASM and data hashes. Rebuild evidence and contaminated-environment check.

Useful next research

Expand whole-program sanitizer coverage and difficult close-encounter/ill-conditioned cases, measure additional browsers and architectures, and investigate certified mixed-precision integration only with explicit error bounds and a reliable high-precision fallback. The measured fitting bottleneck will need work of that kind for a large speedup; lowering precision without such evidence is not part of this port.
